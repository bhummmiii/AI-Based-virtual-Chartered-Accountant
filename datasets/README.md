# 📊 Datasets

Sample datasets for development, testing, and demo purposes.

## Directories

| Directory       | Description                          |
|-----------------|--------------------------------------|
| gst/            | Sample GST returns & invoice data    |
| tax/            | Income tax computation samples       |
| audit/          | Audit report samples                 |
| budget/         | Union budget data                    |
| accounting/     | Chart of accounts & journal entries  |
| ocr_samples/    | Sample invoices/docs for OCR testing |
| translation/    | Multilingual text samples            |
| demo_clients/   | Demo client profiles                 |

## Notes
- Keep file sizes reasonable for version control
- Large binary files should use Git LFS
- Sensitive data must be anonymized
