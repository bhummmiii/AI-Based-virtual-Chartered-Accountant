8. EVALUATOR Q&A / VIVA VOCE CHEAT SHEET
====================================================================================================

Q1: "How do you handle multi-page invoices where line items are on pages 1-4 and taxes on page 6?"
A1: "We built a dynamic multi-page rasterizer using PyMuPDF. All pages are passed in sequence to the
    Gemini Multimodal Vision API with a strict JSON schema prompt. The model captures line items across
    the item tables and resolves the final tax computation matrix on the last page. A mathematical
    reconciliation rule verifies that Taxable Value plus Taxes equals Grand Total."

Q2: "What prevents Client A's financial data from leaking to Client B?"
A2: "Multi-tenant isolation is enforced at both the database and file storage levels. Database queries are
    strictly scoped to Client UUID with foreign key constraints, and uploaded documents are stored in
    isolated physical directories on disk partitioned by client UUID ('uploads/<client_id>/<doc_uuid>')."

Q3: "Why did you use Gemini Vision instead of standard open-source Tesseract alone?"
A3: "Standard Tesseract OCR outputs flat, unstructured text strings and struggles with complex multi-column
    Indian tax invoices with irregular bounding boxes. Gemini Vision provides contextual multimodal
    understanding, directly converting visual layout into typed JSON schemas with HSN decomposition,
    while Tesseract serves as an offline fallback."

Q4: "Is your system compliant with Indian GST laws?"
A4: "Yes. It adheres to Indian statutory requirements: 15-character alphanumeric GSTIN validation, HSN/SAC
    multi-tier tax rate categorization (CGST, SGST, IGST, Cess), Table 12 compliance, and INR (₹)
    financial precision."
